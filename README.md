# TaskFlow

TaskFlow — веб-приложение для управления задачами, разрабатываемое на Go.

Проект создаётся с целью изучения Go, backend-разработки, баз данных и современных инструментов разработки.

В дальнейшем приложение позволит пользователям регистрироваться, создавать задачи, управлять проектами и отслеживать выполнение задач.

## Технологии

**Backend:**
- Go
- net/http

**Frontend:**
- HTML5
- CSS3 (планируется)
- JavaScript (планируется)

**База данных:**
- PostgreSQL (планируется)

**Инструменты:**
- Git
- GitHub
- VS Code

## Структура проекта

- `backend/` — серверная часть приложения на Go.
- `backend/cmd/api/main.go` — точка входа и запуск HTTP-сервера.
- `frontend/` — клиентская часть приложения.
- `frontend/index.html` — главная HTML-страница.

## Запуск проекта

Для запуска необходимо установить Go.

1. Откройте терминал в корневой папке проекта.
2. Перейдите в папку backend:

   `cd backend`

3. Запустите сервер:

   `go run ./cmd/api`

После запуска приложение будет доступно по адресам:

- Главная страница: http://localhost:8080/
- Проверка сервера: http://localhost:8080/health
